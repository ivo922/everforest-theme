# Everforest for Orca

An [Everforest](https://github.com/sainnhe/everforest) theme for [Orca](https://www.onorca.dev):
comfortable green-based dark and light application themes in hard, medium and soft contrast,
with matching terminal colors.

| Dark                    | Light                    |
| ----------------------- | ------------------------ |
| Everforest Dark Hard    | Everforest Light Hard    |
| Everforest Dark Medium  | Everforest Light Medium  |
| Everforest Dark Soft    | Everforest Light Soft    |

Pick a dark and a light variant in Appearance, and the matching palette in terminal settings.

## Attribution

This is an unofficial port of the original
[Everforest theme by sainnhe](https://github.com/sainnhe/everforest). The palettes come straight
from the upstream repository, and the syntax colors follow its Vim highlight groups. Light
shades that are too faint for Orca’s contrast checks are darkened just enough to pass; terminal
ANSI colors use the upstream palette unchanged. Upstream license notices are included in
[LICENSE](LICENSE).
